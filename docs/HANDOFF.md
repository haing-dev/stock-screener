# Stock screener: detailed handoff

Read CLAUDE.md first; this file holds the detail.

## v2.9.0 (Oct 2026): validation
- Pre-registration: `validation/PROTOCOL.md` (data, formation, costs, benchmarks, statistics, mechanical verdicts,
  independent checks), `validation/freeze.json` (rules + behavior fingerprints, `qs/freeze.py`), `validation/CHANGES.md`,
  tag `prereg-2026-10-20`. `tests/run_tests.py` checks the fingerprints still match.
- Forward record: `qs/listlog.py` + `scripts/append_history.sh`; Screen and Daily runs append
  `lists/YYYY/<date>_<kind>.json.gz` (PASS / starred / NEAR per screen, code SHA, config hash) to branch `history`.
- Point-in-time layer: `qs/pit.py` (facts filed before d; filing history -> profile as of d), `qs/btdata.py` (bulk
  companyfacts / submissions incl. older pages -> cache/bt/facts, cache/bt/filings; 10-Q facts since 2009 via
  `facts_subset(quarterly_since=)`). Pipeline steps shared with the live run: `pipeline.metrics_for`, `make_contexts`,
  `apply_industry_cycle`.
- Prices: `qs/btprices.py` - Massive grouped daily UNADJUSTED for each month-end (formation) and the next trading day
  (entry/exit at the open), ticker reference incl. delisted (`resolve(symbol, day)` = earliest delisting after the day),
  full split and dividend lists, `last_close` for exits of delisted names (budget `LAST_CLOSE_BUDGET`), `holding_return`.
- Engine `qs/backtest.py`: company pass (metrics recomputed only when a new filing arrived), formations (live code,
  threshold grid +-10/20/30%, leave-one-gate-out, baseline scores from `qs/btscores.py`), returns. Work files in
  cache/bt/work (resumable). Statistics `qs/btstats.py` (Newey-West, DSR, PBO/CSCV, Reality Check + SPA, placebo,
  AUC), `qs/btanalysis.py` (series, char-matched benchmark, baselines, IC, verdicts), report `qs/valreport.py`.
- Checks: `qs/audit.py` (300 firm-years vs SEC Financial Statement Data Sets; review sheets incl. 50 starred passes),
  `qs/fidelity.py` + `validation/managers.json` (13F style fidelity), `scripts/compare_reimpl.py` (independent
  re-implementation of Fortress from the written rules: `validation/reimpl/`).
- Orchestration: `python screener.py validate {prices,prepare,backtest,stats,audit,fidelity,report,all}`;
  workflow `validate.yml` publishes `out/` to branch `validation` and stamps freeze.json with OpenTimestamps once.
- Offline tests: `tests/validation_smoke.py` (real samples + synthetic prices: PIT filters, no look-ahead, splits and
  dividends, formations, statistics, report), run from run_tests.py.

## v2.8.0 (Oct 2026)
- Menu groups (`portal.SCREEN_GROUPS`): Compounders (core, emerging, fortress, owners, hc_commercial, real_assets); Contrarian & special situations (special, hidden, asset_floor, cyclicals, trough_cash); Frontier growth (tech, hc_clinical); Avoid (red_flags).
- Unverifiable-only misses = PASS with `star` (site asterisk, note 'insufficient information about ...'). Exceptions -> CHECK: a `DEFINING_GATES` rule unverifiable (E4 C7 O4 R4 R5 K4 T4 X3 B6 A4), no financial statements yet (`events_only`), avoid list. No cap on the number of unverifiable rules (user's choice).
- 13F (`holders.SCHEMA` 2): top holders ranked by position / holder's own 13F stock portfolio (options excluded); eligible = portfolio >= $500M and stake >= 0.25% of shares or >= $250M ($25M if share count unknown). Excluded: config `passive` + `exclude` names, and managers with > 1,000 stocks or > $250B across > 500 stocks; fund stats frozen 12 months in `cache/prices/holders/managers.json.gz`. Schema bump forces a one-off rebuild (re-downloads the 13F zips).
- Insiders (`insiders.SCHEMA` 2): sales the same day as an option exercise (M/X/C/O in the same filing) -> `ex_sell`; site column 'Insiders' (after Top holders, both lists) shows open-market buys and discretionary sales only (no 10b5-1, no exercise-and-sell). Data = SEC quarterly Form 345 sets (up to ~3 months behind); daily Form 4 top-up not built.
- EV/Sales (EV / TTM revenue in USD, same basis as EV/EBIT) in `TABLE_METRICS` and company facts; peer tab always shown (info only, no vote unless the basis).
- Couldn't screen: plain blocker + fix (`portal.BLOCKERS`), CSV export button, list grouped by blocker in the check report. Instruction texts removed from the site (13F/insider notes moved to column-header hovers).

## v2.7.0 (Oct 2026)
- Efficiency: `qs/secsync.py` reads SEC daily `master.idx` files since the last run (`cache/sec_sync.json.gz`) -> only companies that filed are re-downloaded (facts only after a 10-K/10-Q/20-F/40-F); safety ages `cache_days_*_indexed`. Full refresh (new SUBSET_VERSION or < 50% cached) uses SEC bulk `companyfacts.zip` / `submissions.zip` (`needs_bulk`, `mark_bulk_done` in `cache/sec_meta.json.gz`). `SCREEN_WORKBOOK=0` skips the Excel workbook (screen.yml input `workbook`).
- Workflows: screen.yml (no holders, quick history), daily.yml (exits early with `new_day=false` when Massive has no newer trading day), new background.yml (cron 40 10 * * *: `portal-background` = 52-week backfill 200 days, Twelve Data history 300 credits keeping `td_reserve_credits` 100, 13F quarterly, insiders quarterly; then Claude descriptions only if `summaries_todo` > 0, committed by `scripts/commit_data.sh`). Caches pruned to the newest per prefix (`scripts/prune_caches.sh`, needs `actions: write`). Publish skipped when the plaintext data + site code digest is unchanged (`cache/state/site_digest.txt`).
- Price history: Twelve Data month-end series fetched once per company (refetch after `history_refresh_days` 730), then extended monthly from Massive month-end closes (`history.extend_histories`, split-adjusted). FX from the ECB daily XML first (`prices.ecb_rates_to_usd`). Massive splits incremental; ticker list cached 30 days; Twelve Data backup skips tickers that failed in the last 30 days (`prices/massive/unpriceable.json.gz`).
- Descriptions write-once (`summaries.needs_summary`): redone only on name/SIC change, a spin-off/bankruptcy/reorg after the summary, or age > 3 years; only listed companies + their peers; Claude runs from an empty temp dir (no CLAUDE.md load).
- Ownership (company page 'Ownership' card): 13F top holders with share of each holder's portfolio, biggest buyers/sellers vs the previous quarter (`holders.build(prev_zf)` -> `buy`/`sell`, `holders.moves`); insider open-market buys / sales / 10b5-1 plan sales over the last 3 quarters (`qs/insiders.py`, SEC Form 345 data sets, AFF10B5ONE flag). Congress trades not built (needs a Quiver API key; the Quiver MCP connector works in chat only).
- Tech S-Curve Leaders screen (`tech`, gates A1-A16, valuation gate A16, hard A4/A14/A15): software branch SIC 7370-7379, hardware 3570-3579/3661-3679/3825/3827 + config allowlist. Rule of 40 after stock pay, SBC <= 20% of FCF, self-funded capex + leverage, 3y incremental ROIC (`metrics.incremental_roic_3y`), DSO (software) / inventory days (hardware), EV/Sales <= growth points / 3 (max 15x). Excluded by the user: market position, net retention, AI share of sales, customer concentration, China/Taiwan exposure.
- Code split for smaller reads: site text in `qs/screen_text.py` (RATIONALE/PURPOSE); Excel model builder in `site/model.js` (lazy-loaded with ExcelJS).

## Design notes up to v2.6 (Oct 2026)
- Python screener over SEC XBRL companyfacts + submissions; prices from Massive (ex-Polygon, free plan 5 req/min: grouped daily, unadjusted month-end history in `hist_raw`, adjusted `hist`, split list from /v3/reference/splits); Twelve Data = backup + FX.
- 13 screens (v2.6; Tech added in v2.7) in `qs/screens.py`: first batch Core, Emerging, Special, Fortress, HC Commercial, HC Clinical, Cyclicals; second batch (strict) Owners, Hard Assets, Asset-Floor, Trough Cash, Hidden Earnings, Red Flags (avoid list). Thresholds in `config.json`.
- Gate statuses PASS/FAIL/NO DATA/N/A; company classes PASS/CHECK/NEAR/PRICE/ONE/FAIL. HARD_GATES = defining rules; VALUATION_GATES = E12,C8,O11,R10,T8,X9. `site/app.js` statusOf mirrors the Python logic. Site shows two lists: Pass (PASS) and Near misses (CHECK+NEAR+PRICE+ONE, each with its reason).
- Core (Oct 2026): G2 recent report applied but hidden (`Gate.hidden`, all screens); G4 <= 2 loss years; G9 no operating loss in a downturn FY (2008-09, 2015-16, 2020, 2022; `metrics.DOWNTURNS`) while sales fell, only downturns inside SEC data; G10 3y revenue CAGR >= 0 (sole failure = near miss). Quality warnings removed from every screen. Rationales on the site = `screens.RATIONALE` / `PURPOSE` (no investor names; attributions stay in the criteria workbook).
- Portal: AES-GCM encrypted data (PBKDF2 from PORTAL_PASSWORD). Same table columns on every screen (`portal.TABLE_METRICS`). Company page (#screen/TICKER): about, valuation vs 10 closest peers + own 3y/10y average multiples (`qs/history.py`, info only, listed companies), Excel 3-statement model built in the browser (`site/vendor/exceljs.min.js`, `buildModel` in app.js) from `state.models` (`metrics.model_years`, 10 FYs, shares restated to today's basis) exported as `model_XX.bin` shards.
- Price history (`history.update`, screen + daily runs, budgets in config `portal`): 52-week range from Massive weekly high/low files (`cache/prices/massive/weeks`, backfilled ~100-200 days/run, shown once >= 240 days); month-end prices from Twelve Data (`cache/prices/monthly_history.json.gz`, 1 credit/company, listed + peers, refetch after 180 days or a split).
- `extract.SUBSET_VERSION` 8 (v2.6) -> next screen run re-downloads all SEC facts (model concepts `model: True`, annual only; v8 added impairments, exploration, benefits, premiums, cash_cf_end, cash_change, lease liabilities for the industry Excel templates).
- Metric audit (Oct 2026, v2.5): ROIC uncapped (floor -500%); capital-light years (invested capital <= 2% of revenue or negative, with profit) = n/m and count as above any >= floor (`_median_nm`, `<metric>_nm` notes; Gate PASS with note). Revenue growth uses a like-for-like chain from same-filing ratios (`CompanyData.revenue_ratios`, restatements/disposals); `revenue_cagr_raw` kept. Agg "max" for capex/R&D/D&A/other debt; extra capex, securities, lease, commercial-paper tags; EV/net debt subtract long-term investments; missing capex/SBC = None (not 0); 3y ratios need all 3 years. Known limits: derived revenue (e.g. NVS) gets no chain; annual EBIT keeps interest income; no debt tags = debt-free.
- Thesis update from 98 new transcripts (v2.5): G7/H7/O7 cash conversion = (FCF - stock pay)/net income (MSFT now near miss on G7); Emerging E3/E12 use EBIT / EV-EBIT when D&A >= 50% of EBITDA (`_capital_heavy`); Asset-Floor tangible-book route needs tangible book/share not down over 3 yrs; Red Flags W4 + 6 signals (profits above cash 2y, negative OCF, restructuring >= 4 of 5 yrs, acquisitions > OCF 3y, inventory days 5y high, heavy capex with negative FCF).
- Site v2.6 (Oct 2026): thesis card at the top of each screen (`qs/thesis.py`: definition -> traits + cause -> sourced example; no investor names). Near-miss list = dot table (green pass / amber miss with one-line reason 'Miss due to <what> being <value> (needs <rule>)' from gate `what`/`need`/`ftxt` in `portal.SUBJECT`/`FAIL_TEXT`, ranked by rules met). Top-5 holders column + company-page holders card from `qs/holders.py` (SEC 13F data sets; CUSIP->ticker via OpenFIGI, optional secret OPENFIGI_API_KEY; cache under cache/prices/holders; config portal.holders passive/specialists lists). Company page peers: mean/median rows + 'Operating metrics' tab (`history.PEER_OPS`). Excel model: industry templates (`industry.model_template`: software, hc_products, biotech, insurer, hc_services, resources, homebuilder, tech_hw, transport, consumer, industrial), unreported lines dropped, plugs tie the statements, Cover lists checks (BS balances, beginning cash + change = ending cash). Design: Instrument Sans + Newsreader, cobalt accent; 21st.dev MCP not connected (needs API_KEY_21ST).
- Healthcare (v2.6, from transcripts): H6 drug makers >= 65% gross margin (devices/tools 50%); H4/H5 N/A for a new launcher (TTM op income > 0, 3y revenue CAGR >= 25%, product margins); B2 near miss when 2-yr funding gap <= 20% of market cap; new B7 (valuation gate) market cap / (cash - debt - 1 yr burn) <= 1.25.
