## What the A1 job does (on the PC)

1. Checks, and stops before reading any Bloomberg value if one fails: the gm code in local\lib\gm equals the
   reference's (lib\engine_ref.json, gm-2.2.0 code block); the store in local\work\bbg has lock id LOCK_v2
   d85a46cb2853646b24796f294f3ccab1d1507188c402e978fd59f5196ea41fc9; the free inputs (local\work\free zip) match the
   reference's file list and sizes.
2. Builds the free inputs exactly as the engine does (every loader cut at 2010-12-31) and evaluates every registered
   candidate: block 1, the 31 GSCI / BCOM excess-return indexes of the 16 panel commodities (panel return); block 2,
   CL / NG / HO / XB generic contracts 1 and 2 (EIA contract prices of the Carry signal); block 3, the MSCI 12-month
   dividend yield of 15 equity markets (Value); report line R, 11 first bond futures against the yield-built bond
   returns. One line per series: ADMITTED / REJECTED / REPORT ONLY, status in LOCK_v2, first date in the lock and count
   (as of 2010-12-31), first month used, free first month, overlap months, correlation (printed only over at least
   60 months), extension months, instrument, reasons. This is also the LOCK_v2 part of the metadata listing.
3. Builds the A1 panel for each block alone and for all blocks, checks extension-only (no free month changed, only
   months before each free start filled), prints the A1 PANEL ID and the extended series (first..last month, count),
   and writes the panel values only to local\work\a1\a1_panel_<id12>.pkl.
4. Runs the registered report: A1_INCUMBENT (CANDIDATE gm-2.0.3 + E13) at k = 1, and k = 0 beside, on free data and
   on each arm (block b alone, then all blocks); 1975-2010, 1975-89, 1990-2010; net Sharpe, mean, volatility, worst
   drawdown, dSR with lb95 and se against the free arm; family x class blocks that differ; k = 1 flagged share.
   Summary statistics over at least 60 months only. No adoption test.
5. Prints TRIAL ROW {...}: the gm/trials.csv row (family "data") for the coordinator to append.

## Closed here (also in the two CHANGES entries)

X1 / E13: plain share of the 12 calendar-month means (R^2 on month dummies); the gate also needs at least 5 values in
every calendar month (the spec's "five" is the adjustment's minimum of earlier same-month values); window from the
first signal month; trailing 12-month mean needs all 12 month-ends; "earlier" = strictly before t; E13 as a config key
held by A1_INCUMBENT and the A2 challenger (BASE and CANDIDATE unchanged, the 7.4 feature-version gate); both A1 arms
use A1_INCUMBENT.
A1: candidate blocks 1-3 and report line R from the specs' own A1 lines and the engine's Bloomberg map (EquityTR,
yields, FX, first-release economics, alternative commodities, far curve points and other valuation fields are not
candidates); status ok = a primary series id (copies have none), no _CUT file, not held back; extension = months
strictly before the free first month (interior gaps never filled); correlation over at least 24 overlap months
(printed only over 60); returns: index change through gm's own commodity_return route (C4 gate), contract month-end
price change, dividend-yield monthly change; preference GSCI then BCOM month by month; carry recomputed only before
the free carry starts; dividend yield / 100 at E4's lag; signals recomputed on the extended panel.
