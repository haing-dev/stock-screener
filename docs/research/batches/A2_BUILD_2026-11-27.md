## What the A2 job prints (tools/bbgq/jobs/gm_a2_v1.py on the PC)

1. Checks, each PASS / FAIL, and STOP before any Bloomberg value is read on a FAIL: gm .py files = engine_ref.json's
   code block; a2_batch.py, a1_panel.py, gm_engine.py, bbg_panel.py, bbgdata.py = the sha256 in the job (table below);
   lib\gm\trials.csv = 2b80e2f9...e178a36 (the trial log the selection inflation is computed from, with the two
   gm-2.2.1 fix rows); local\results\gm_a1_v2.txt usable (A1 JOB DONE, the registered A1 PANEL ID, the three as-run
   lines); store lock id =
   LOCK_v2 d85a46cb...ea41fc9; free inputs = the reference's file list and sizes.
2. Free arm vs engine_ref.json (signal sums E / C / V, market months); then the A1 panel is rebuilt by a1_panel-1.1.0
   (evaluate + build, all blocks; about 4 minutes), extension-only asserted, `PASS A1 PANEL ID e7f98d44...` required,
   and compared with `work\a1\a1_panel_e7f98d4439fc.pkl` if present (STOP on any difference); EXTENDED lines (the
   three extensions of the A1 run).
3. `PASS incumbent as run (A1 report ...)`: the incumbent's net Sharpe 1975-2010 (k1, k0, d1) must equal the
   "all blocks (A1 panel)" 1975-2010 lines of gm_a1_v2's report; else STOP with nothing else printed.
4. The registered report (a2_batch.report):
   - `HYGIENE | k1 | ...` = the DECISIVE line: n, dSR, lb95, se, H1, H2 (double costs, reported), H3 with its two
     margins and both books' max drawdown; the same lines for k0 and d1 (reported);
   - `ERA | ...` per timing and era (1975-89, 1990-2010): dSR, lb95, se, H3 margins;
   - selection inflation: 39 logged book rows, mean 1.481, sd 0.118, z 2.18 -> +0.26 (registered; recomputed by the job
     from the shipped trial log); the tuned-knob line (Trend 4, Economic trend 3, Carry 3, Value 3 + 1 seen leg, book 3);
   - `BOOK | ...` 36 lines: each book x k1 / k0 / d1 x single / double costs x 1975-2010 / 1975-89 / 1990-2010: months,
     net Sharpe, mean, volatility, max drawdown, skew, Lo-adjusted Sharpe;
   - `VERSION | ...` 22 lines: each challenger version alone (one-part equal-risk book, k = 1) by era; share of versions
     with net Sharpe > 0 per pod and overall; `POD | ...` 10 lines: each pod alone for both books, the incumbent's Carry
     v1 and v2;
   - `CLASS | ...`: family x class contributions (k = 1, before costs), family totals, class totals, both books, by era;
   - `TRANCHE | ...`: weekly check 1990-2010, tranche j = 0..3 and the tranche form per book with the flagged share;
     dSR of the tranche forms with lb95 (reported);
   - `SPLIT | ...`: the exactness check (parts add to the held Trend position) and the class-average / relative parts of
     Trend, total and per class, both books, by era;
   - `CARRYPRICE | ...`: covered share; Trend's bond + currency total, carry part, price part (Sharpe and mean) by era;
   - `VALUE | ...` 3 lines (Value v1 / old Trend; Value v1 + v2 / old Trend; Value v1 + v2 / 16-version Trend):
     correlation, NW t of Value's intercept on Trend, correlation with Trend's relative part; `ECON-TREND | ...` 2 lines;
   - `FLAGGED | ...` k = 1 flagged share 1975-2010 and by year, both books; `P4 | ...` book and specific Sharpe
     1978-01..2010-12 (S&P alone, M1 not yet run);
   - `FRAGILITY | ...`: largest loss of the pooled dSR when one year, one market (every panel column, both books re-run)
     or one class is removed, and the 40% year flag;
   - `A2 VERDICT PASS | ...` or `A2 VERDICT FAIL | ...` with the A2-final book's name and hash.
5. `TRIAL ROW {...}`: the gm/trials.csv row, family "book", hash 1faa343535, note with the panel id, LOCK_v2, engine,
   parent A1_INCUMBENT 77374d7bef, the verdict and the H1 bound. Then `A2 JOB DONE`.
Only summary statistics over at least 60 months, pass / fail, counts and ids are printed (export whitelist); worst
months are printed only as H3 margins. Nothing is written to `work\`. Expected run time: about 10-15 minutes (A1
rebuild about 4 minutes; about 190 book runs, most of them the fragility re-runs).

## How the coordinator queues it

Prerequisite: the PC runner is up and imports pandas; work\bbg (LOCK_v2 store) and the free inputs zip in place.

1. Build the package in the cloud: `python3 tools/bbgq/build_engine.py` (fills tools/bbgq/engine_pkg/, git-ignored;
   engine_pkg/DEPLOY.txt lists every file, size and PC destination).
2. Copy to `C:\Users\admin\Documents\WRDS results\local\` (same relative path): the CHANGED files `lib\gm\book.py`,
   `lib\gm\config.py`, `lib\gm\run.py`, `lib\gm\trials.csv`, `lib\gm\CHANGES.md`, `lib\engine_ref.json`,
   `lib\a2_batch.py`, and the jobs below; the other lib files are unchanged (copy only if the PC copies differ). The free
   inputs zip is unchanged.
3. Read every copied file back (stage it) and compare its sha256 with the table below BEFORE queuing.
4. Queue the k = 0 reproduction against the NEW reference: copy `jobs\gm_repro_v1.py` to `local\jobs\gm_repro_v7.py`.
   Gate: last line `REPRODUCTION PASS` (24 of 24, difference 0).
5. Queue the A1 rerun: copy `jobs\gm_a1_v2.py` to `local\jobs\gm_a1_v2.py` (about 8 minutes). Gate: `A1 JOB DONE`,
   `PASS lib engine_ref.json`, `A1 PANEL ID e7f98d4439fccf91f3451bc4b9e78079e3bc2cc2452931363b28520460b6cb43` (another id
   is a finding: stop and report), and the "all blocks (A1 panel)" k1 / k0 / d1 1975-2010 lines. Leave
   `local\results\gm_a1_v2.txt` where it is (the A2 job reads it); commit a copy to tools/bbgq/results/gm_a1_v2.txt,
   append its TRIAL ROW (family "data", the gm-2.2.1 A1 row) to gm/trials.csv only AFTER the A2 run (the A2 job checks
   the trial log hash 2b80e2f9...), and record the panel id line under the A1 entry.
6. Queue A2: copy `jobs\gm_a2_v1.py` to `local\jobs\gm_a2_v1.py`; read `local\results\gm_a2_v1.txt` (errors
   `gm_a2_v1.err.txt`); about 10-15 minutes.
7. After the run: append the gm_a1_v2 and gm_a2_v1 TRIAL ROWs to gm/trials.csv (with `when`); append an "A2 RUN"
   paragraph to the A2 entry in gm/CHANGES.md (verdict, decisive line, A2-final book); commit the report to
   tools/bbgq/results/gm_a2_v1.txt. Then 7.6 step 4: the diagnostics of 7.5 order item 2 on the A2-final book.
