## How to add material
Save each document as its own file (PDF or text; name `Investor - Title - Year`) in the raw transcripts folder on
the PC so that DocProcessor gives it line anchors like the transcripts. Letters and manuals count as written
primary sources; their date is the thesis date used in the tests. The pilot reading of Terry Smith and Zlatev
waits for rows 1 and 2; Greenblatt can start as it is.
