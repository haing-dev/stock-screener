## How each investor was graded
A = the stated criteria are mostly measures a script can compute from accounts, estimates and prices. B = a calculable core with judgement on top, or a need for sector data or a stand-in for the investor's own value estimate. C = judgement-led: no screen can be built from what they say.
Basis: the criteria already coded for the old screens (`docs/criteria/Screener_Criteria.xlsx`, with its Easy / Partly marks), the inventory's explicitness score, and my single read of the note of each investor's most explicit document. The measured version (share of criteria a script can compute) comes from the pilot.

## Data source
LSEG first for company data, history and live. The 2010+ window makes this workable: LSEG's known gap is companies that died before 2006, and it holds first-reported accounts from 1983 and consensus from 1990. A manager's whole portfolio is not available on LSEG (probe of 18 Nov), so holdings with conviction come from the SEC's 13F files or WRDS. WRDS stays as the cross-check. With LSEG first, agents need no raw WRDS rows.
