# Hidden-error check: answers

| Excerpt | Verdict | Line (quoted) | What goes wrong | Confidence |
|---|---|---|---|---|
| E1 | DEFECT | `bps = np.percentile(cap[u], [20, 40, 60, 80])` | The size breakpoints come from the whole universe (NYSE, NYSE American and Nasdaq). Spec 4.3 and build note 3.8 say "NYSE breakpoints use the NYSE stocks of that universe". The `ny` mask is computed and checked (`ny.sum() < 5`) but never used, so the line should be `cap[ny]`. With all-exchange breakpoints the small-cap fifths fill with Nasdaq micro-caps and every DGTW group shifts. The other dates are correct: size and exchange at June fy, momentum June fy-1 to May fy, weights from the previous month-end, groups held July to June. | high |
| E2 | CONFORMS | - | Only first versions are used (`fdate = rdate`) and shares must be positive. The CUSIP is matched with namedt <= rdate <= nameenddt, and ties go to the lowest permno (`distinct on ... order by n.permno`). The CRSP price is taken in the quarter-end month (yyyymm of rdate). Filed value uses the 13F price, 0 if missing. Matched value is shares x \|CRSP price\|, and npos is the number of distinct matched permnos. All of this matches build note 3.6. | medium |
| E3 | DEFECT | `if per.get(p["style"], 0) > STYLE_CAP:` | It should be `>=`. With `>`, a style gets a ninth record place before the cap binds. Spec 7.3 says "at most eight per primary style". | high |
| E4 | CONFORMS | - | The CUSIP must be valid at the quarter-end (rdate inside namedt..nameenddt), with ties to the lowest permno. The price is CRSP at `_qend_mi(q)`, and rows without a price are dropped. Weight is shares x price. Filed value counts all rows and used value counts the matched rows. This matches spec 3.2-3.3 and build note 3.6. | medium |
| E5 | DEFECT | `for k in range(int(h.max())):` (so `mi = em + k`) | The first month held is `em`, the month in which the 45-day deadline falls. Holdings enter only at its close (`_entry_mi` docstring; `_win_span` uses em+1..em+H; spec 3.4: 31 March holdings are held June, July and August, while em = May). So the code earns the May return on holdings that were not yet public, a one-month look-ahead, and it drops the last month em+H. The loop should run k = 1..H (`range(1, int(h.max()) + 1)`) with `act = h >= k`. With the current loop, `act = h >= k` also leaves a 3-month book active at k = 3 when another book holds 6. | high |
| E6 | DEFECT | `f["w"] = np.where((pf == f.crsp_fundno) & (pm == f.mi - 1), f.mtna, np.nan)` | The class weight is the same month's end TNA (`f.mtna`). It should be the previous month-end TNA (`f.mtna.shift(1)`). The code checks that the previous row is the previous month, then uses the current value anyway. Spec 5 and build note 3.13 require assets at the start of the month. As written, the weights take in the month's own return and flows, which is a look-ahead. | high |
| E7 | CONFORMS | - | OLS with an intercept, Bartlett weights 1 - lag/(L+1) with L = 3, sandwich (X'X)^-1 S (X'X)^-1, and small-sample factor n/(n-k). This is the form build note 3.20 allows. | high |
| E8 | DEFECT | `f["H"] = np.where((nxt - f.q) >= 2, 6, 3).astype("int64")` | It should be `== 2`. With `>= 2`, gaps of three or more quarters are also bridged to six months. Spec 3.5, spec 12 and build note 3.4 bridge only a next filing exactly two quarters later; a longer gap ends the spell after three months. A missing next filing gives NaN, which correctly falls to 3. | high |
| E9 | CONFORMS | - | `_share`: (below + 0.5 x equal) / len(pool without own entries). The library investor stands in for its own filers, so len(v) = group size - 1. It is missing unless one of its own filers is in the pool (build note 3.1). `_member_shares`: (average rank - 1)/(n - 1), which is the same formula for members. `_blockpos` counts blocks with at least 36 months and the share with alpha > 0. bpool takes filers in the rank group of at least one block (build note 3.15). | medium |
| E10 | DEFECT | `L.append(_wline(d["id"], w, s, full_rec or s.get("n", 0) >= MIN_RESULT))` | The window threshold is MIN_RESULT (36). Spec 8 and spec 12 / build note 3.19 print statistics only if the window or the whole 2011-25 record has 60 months (MIN_STATS). As written, a window with 36-59 months, from an investor whose record is under 60 months, prints full statistics where only rank shares are allowed. | high |
